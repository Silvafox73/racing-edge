RACING EDGE — Android PWA starter (Version 1)

This is a phone-friendly web app that can be installed on Android from Chrome once hosted on HTTPS.

Files:
- index.html: app
- manifest.json: install settings
- sw.js: offline cache
- icons/: app icons

IMPORTANT:
The horses, racecourses and odds shown in the first screen are fictional demo data. There is no live racing feed in this version and it does not place bets.

To install:
1. Upload the CONTENTS of this folder to a GitHub repository (not the ZIP itself).
2. In GitHub, open Settings > Pages.
3. Under Build and deployment, choose Deploy from a branch, select main and /(root), then Save.
4. Open the published HTTPS Pages address in Chrome on your Samsung phone.
5. Chrome menu (three dots) > Install app (or Add to Home screen).
